Citation Concentration and Leading Precedents

The ten most cited cases receive 3.4% of citation links in 2004 and 4.0% in 2024. These percentages divide the links received by exactly ten leading cases by all citation links in that term.

The tables below answer a different question: what percentage of source cases cite each precedent? Each source counts at most once per precedent; zero-citation sources remain in the denominator. Percentages are not shares of all links and need not sum to 100%.

All cases tied at the tenth position are displayed, so each table can contain more than ten rows. Equal counts have equal ranks; tied cases are ordered by name and ID. Definition and Unit of Analysis

Age = source decision year − cited decision year. This is a calendar-year difference, not elapsed time to the day. Term labels are not decision years: the October 2024 term includes opinions decided in 2025.

Each distinct source–target pair counts once. If five source opinions cite the same precedent, it contributes five ages. Repeated mentions within one source contribute only one age. Zero-citation sources count toward links per source but contribute no citation ages. The distribution is weighted by links, so opinions with more links contribute more observations.

Limitations of the Comparison

The two term datasets do not establish a historical trend or a change in the Court’s reliance on precedent. Extraction methods and coverage differ, issue mixes differ, and unresolved references are omitted. A citation alone does not indicate agreement, legal weight, or how heavily an opinion relies on a case.

Data Sources and Coverage

The 2004 dataset uses Harvard archive opinion-block citation links; the 2024 dataset uses official Supreme Court PDF text with resolved case metadata. Majority/per-curiam source opinions follow the existing argued-case selection rule. Mixed majority/plurality sections can be held for review.

  • 2004: 70 included source opinions; 5 additional source case(s) held for review. 83 flagged citation-review entries (not a count of all missing citations).
  • 2024: 58 included source opinions; 1 additional source case(s) held for review. 68 flagged citation-review entries (not a count of all missing citations).

The 2024 source set includes three argued per-curiam dismissals with zero links. Short-form-only and unresolved order citations can be missed. Review queues and selected opinion audits document known issues; they do not establish complete recall.

Sources: Supreme Court Database, release 2025_01; Harvard Caselaw Access Project; Supreme Court 2024 term opinions. Selected case identities were supplemented with CourtListener metadata. Individual CSV inputs and their SHA-256 fingerprints are recorded in citation_age_summary.json.

Reproducibility

From the project folder, create an environment once, then run the report generator. It uses the saved curated CSVs and makes no API requests.

python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements-report.txt
python3 make_report.py

start.py contains the graph and metric functions. make_report.py reuses them to write this standalone HTML report, PNG and SVG charts, and a JSON summary under reports/. Inspect the per-term case_review.csv, citation_review.csv, and audit files before extending the interpretation.
